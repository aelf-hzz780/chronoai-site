What NyxID protects

Three layers, working together.

Credentials stay in NyxID.

NyxID proxies requests and injects credentials on the service side, so the agent does not receive the original service credentials.

A scoped Agent Key for each agent.

Give each agent its own Agent Key. Configure permissions and service access for the work it needs to do.

Human approval, when you want it.

Human approval is available as an option. It is not required for every request.
